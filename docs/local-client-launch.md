# Запуск локального Telegram в Windows

Для обычного запуска из этого checkout используйте `run-debug.cmd`.
Он запускает `out\Debug\Telegram.exe` с аргументами
`-workdir "<checkout>\out\local-profile" -noupdate`.
Профиль аккаунта хранится в `out\local-profile`; `-noupdate` отключает
проверку обновлений при запуске, чтобы использовать собранную здесь версию.
Пересборка и перезапуск описаны в [rebuild-debug.md](rebuild-debug.md).

## Автозагрузка

Пользовательский ярлык `Telegram.lnk` в папке `shell:startup` заменён
с официальной установки на локальный `out\Debug\Telegram.exe`.
Аргументы: `-workdir "<checkout>\out\local-profile" -noupdate -startintray`.
При входе в Windows клиент запускается в трей. Запись разрешена
в `StartupApproved\StartupFolder`.

Здесь намеренно используется `-startintray`: запуск с `-autostart` дополнительно
проверяет внутреннюю настройку Telegram и может сразу завершиться, если она
выключена. Автозагрузка настроена через Windows. Переключение встроенной
настройки автозапуска в любой установленной версии Telegram может удалить
или перезаписать общий `Startup\Telegram.lnk`; после этого проверьте его цель
и аргументы. Текущая реализация `ManageAppLink()` не сохраняет `-workdir`
и `-noupdate` при создании ярлыка.

## Панель задач

В меню «Пуск» подготовлен ярлык `Telegram Local`. Его цель — непосредственно
`out\Debug\Telegram.exe`; аргументы и профиль совпадают с `run-debug.cmd`.
Созданный клиентом ярлык `Telegram.lnk` в корне пользовательского меню «Пуск»
также исправлен: ему добавлены явные `-workdir` и `-noupdate`.

1. Открепите старые значки официального Telegram от панели задач.
2. Найдите `Telegram Local` через «Пуск» и выберите «Закрепить на панели задач»
   (при необходимости через «Дополнительно»).
3. Запустите его. Значок должен представлять работающее окно; после полного
   выхода из клиента этот же значок запускает локальную сборку с тем же профилем.

Для закрепления используйте подготовленный ярлык EXE. У ярлыка и процесса
должен совпадать `System.AppUserModel.ID`: это связывает окно с кнопкой панели
задач, как описано в [документации Microsoft](https://learn.microsoft.com/en-us/windows/win32/shell/appids).
У этой сборки идентификатор зависит от явно заданного пути профиля;
у официальной установленной версии другой идентификатор. Проверенный здесь:
`Telegram.TelegramDesktop.36faeced4a62702927a39eadbd66d912`.
Перенос checkout или смена профиля требуют обновить ярлыки и закрепление.

Проверено: запуск через `Telegram Local` передаётся уже работающему процессу
локальной сборки, второй клиент не остаётся. Вход в Windows и ручное закрепление
после настройки не проверялись; работающий клиент для проверки не закрывался.

## Восстановление

Оригинальные изменённые ярлыки сохранены в
`out/windows-integration-backup-20261017-214748/`:
`Startup-Telegram.lnk` и `StartMenu-Telegram.lnk`.
Для возврата официальной автозагрузки скопируйте `Startup-Telegram.lnk`
в `shell:startup` под именем `Telegram.lnk`.
